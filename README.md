# Senify Salon — Hair & Beauty Website

A one-page website for **Senify Salon**, a hair and beauty salon in Lagos, Nigeria.

Built as a beginner HTML and CSS learning project.

> GitHub Pages link to be added after deployment.

## 📋 Sections

| # | Section | Description |
|---|---------|-------------|
| 1 | Home | Full-screen hero banner with background photograph |
| 2 | About | Salon photograph and description of the brand |
| 3 | Services | Braiding, Weaving, and Wig Installation cards with prices |
| 4 | Products | Seven product categories: Wigs, Weaves, Extensions, Creams, Skincare, Makeup, Nails |
| 5 | Gallery | Eight-photo masonry grid of hairstyle and product images |
| 6 | FAQ | Seven accordion questions using `<details>` and `<summary>` — no JavaScript |
| 7 | Contact | Enquiry form and contact information |

---

## 🛠️ Technologies Used

- **HTML5** — Semantic elements: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>`, `<details>`, `<summary>`
- **CSS3** — Custom properties (variables), Flexbox, CSS Grid, `clamp()` for fluid typography, `object-fit: cover`, media queries for responsiveness
- **No JavaScript** — All interactive elements (navigation, accordion FAQ) work with HTML/CSS only
- **No frameworks** — Pure hand-written HTML and CSS
